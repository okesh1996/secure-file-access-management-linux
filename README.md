<h1>Secure File Storage and Access Management for Project Teams</h1>


<h2>Objective</h2>
To develop a secure file storage and access system for finance teams at ABCD Financial, focusing on user access controls, ACL permissions, command history management, and security violation reporting.
<br />


<h2>Description</h2>
The project aims to enhance file security and access management, prevent unauthorized modifications, and ensure compliance with audit requirements. It focuses on role-based access control, command history tracking, and real-time security monitoring to mitigate risks.
<br />


<h2>Tools Used</h2>

- <b>Linux Command-Line & ACLs
  <br /> 
- <b>Shell Configuration</b>
- <b>Syslog/Rsyslog</b>
- <b>HTML & PHP (Web Reporting Interface)</b>

<h2>Environments Used </h2>

- <b>LINUX </b> (KALI)
